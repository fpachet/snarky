# Grands projets

Les grands cas d'étude restent autonomes :

- [`Sudoku`](../../sudoku/README.md) teste la résolution progressive,
  l'élimination de candidats, les groupes de techniques et les explications ;
- [`Spinoza`](../../spinoza/README.md) teste une base de connaissances étendue,
  la reconstruction de preuves et la traçabilité historique.
- [`Solveur CSP`](../../csp_solver/README.md) teste le protocole factuel de
  domaines, la propagation, les choix et le backtracking ;
- [`Harmoniseur SATB`](../../harmonizer/README.md) teste la combinaison de
  contraintes dures, recherche best-first et poids marginaux.

Ils ne sont pas recopiés sous `rulebases/` afin de conserver un seul chemin
canonique pour leurs corpus et leurs rapports.
