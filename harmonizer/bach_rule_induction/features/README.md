# Feature registry

Chaque feature musicale recevra un identifiant stable, une définition lisible,
une sémantique de calcul, un domaine, une provenance et des tests positifs,
négatifs et limites.

Une feature ne doit pas encoder l'identité d'une pièce. Une nouvelle feature
proposée à partir d'une erreur de DeepBach doit distinguer une paire minimale
qui était auparavant indiscernable.
