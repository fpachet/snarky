# License status

No license has yet been selected for the Snarky project.

This file is deliberately not a software license. In the absence of an
explicit grant, the repository must not be presented as open-source or
published as a reusable package. Normal copyright exceptions may vary by
jurisdiction; this statement is not legal advice.

A public package upload or version tag is blocked until the project owner:

1. selects a license for original Snarky code and documentation;
2. confirms that all contributors can grant the necessary rights;
3. adds the complete license text as `LICENSE`;
4. updates `pyproject.toml`, `CITATION.cff`, and the release notes;
5. resolves the external-material decisions recorded in
   [THIRD_PARTY.md](THIRD_PARTY.md).

The source and wheel build checks intentionally make no license claim.
